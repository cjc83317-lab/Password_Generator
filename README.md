# 🔐 Password Generator

A simple, original Python script to generate secure passwords and rate their strength.

## Features
- Choose password length (6–64 characters)
- Include uppercase, digits, and symbols
- Generates multiple passwords at once
- Rates strength as WEAK ⚠️, MEDIUM ⚡, STRONG ✅

## Usage
```bash
python password_generator.py
